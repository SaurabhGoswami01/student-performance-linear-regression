# Student Performance Prediction using Linear Regression

## Overview
This project predicts students' final grades using Linear Regression on the UCI Student Performance Dataset.

## Features Used
- Study Time
- Previous Failures
- Absences
- G1 (First Period Grade)
- G2 (Second Period Grade)

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Results
- MAE: 1.34
- RMSE: 2.11
- R² Score: 0.782

## Visualizations
- Study Hours vs Marks
- Actual vs Predicted Student Grades

## Learning
- Data preprocessing
- Train-test split
- Linear Regression
- Model evaluation
- Data visualization
